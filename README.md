# IT102-Final-Project--TAGHOY-DEL-MAR-

**Project Overview**

**This project is a C program that brings together four different activities in one menu. Users can create star patterns, generate Pascal's Triangle, calculate grades, and check if a word is a palindrome.**
**It uses basic C programming skills, including loops, conditions, variables, arrays, strings, and user input.**

**Features**

**1. The Pattern Generator**

Allows users to create different star patterns by choosing a shape and entering the desired number of rows.

**Available Patterns:**
1. Right Triangle
2. Square
3. Isosceles Triangle
4. Inverted Right Triangle
5. Christmas Tree

**2. Pascal's Triangle**

Creates Pascal's Triangle according to the number of rows entered by the user.

**Features:**
1. Displays numbers in a triangle format.
2. Automatically calculates the numbers in each row.
3. Uses nested loops to arrange the output.

**3. Grade Calculator & Evaluator**

Computes the student's average grade using four grading periods.

**Required Inputs:**
1. Prelim Grade
2. Midterm Grade
3. Pre-Final Grade
4. Final Grade

**Features:**
1. Accepts grades from the user.
2. Calculates the overall average.
3. Displays the grades and final average with two decimal places.
4. Determines whether the student passes or fails.
5. PASS: Average is 3.00 or lower.
6. FAIL: Average is higher than 3.00.

**4. Palindrome Checker**

Determines whether a word is the same when read forward and backward.

**Features:**
1. Accepts a word from the user.
2. Checks the characters from both ends.
3. Ignores differences between uppercase and lowercase letters.
4. Displays the result of the check.

**Examples:**
1. Level – Palindrome
2. MadaM – Palindrome
3. Hello – Not a Palindrome

**Try Again Operation**

1. Once an operation is finished, the program asks if the user wants to perform another task.
2. Enter Y to go back to the main menu.
3. Enter N to close the program.
4. This allows users to use different features without running the program again.

**Technologies Used**
1. Programming Language: C
2. Compiler: GCC or any compatible C compiler.

**Libraries Used:**
1. stdio.h – Used to display information and receive user input.
2. string.h – Used for string-related operations, such as strlen().
3. ctype.h – Used to convert characters using tolower().

**Programming Concepts Applied**

1. Variables and Data Types
2. Input and Output (scanf() and printf())
3. Conditional Statements (if, else if, and else)
4. Loops (for and do-while)
5. Nested Loops
6. Arrays and Strings
7. String Functions (strlen())
8. Character Functions (tolower())
9. Mathematical Operations
10. Logical and Relational Operators
