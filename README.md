# IT102-Final-Project--TAGHOY-DEL-MAR-

**Project Overview**

**This project is a C program that brings together four different activities in one menu. Users can create star patterns, generate Pascal's Triangle, calculate grades, and check if a word is a palindrome.**
**It uses basic C programming skills, including loops, conditions, variables, arrays, strings, and user input.**

**Features**

**1. The Pattern Generator**

Allows users to create different star patterns by choosing a shape and entering the desired number of rows.

**Available Patterns:**
1. Right Triangle
2. Square
3. Isosceles Triangle
4. Inverted Right Triangle
5. Christmas Tree

**2. Pascal's Triangle**

Creates Pascal's Triangle according to the number of rows entered by the user.

**Features:**
Displays numbers in a triangle format.
Automatically calculates the numbers in each row.
Uses nested loops to arrange the output.

**3. Grade Calculator & Evaluator**

Computes the student's average grade using four grading periods.

**Required Inputs:**
Prelim Grade
Midterm Grade
Pre-Final Grade
Final Grade

**Features:**
Accepts grades from the user.
Calculates the overall average.
Displays the grades and final average with two decimal places.
Determines whether the student passes or fails.
PASS: Average is 3.00 or lower.
FAIL: Average is higher than 3.00.

**4. Palindrome Checker**

Determines whether a word is the same when read forward and backward.

**Features:**
Accepts a word from the user.
Checks the characters from both ends.
Ignores differences between uppercase and lowercase letters.
Displays the result of the check.

**Examples:**
Level – Palindrome
MadaM – Palindrome
Hello – Not a Palindrome

**Try Again Operation**

Once an operation is finished, the program asks if the user wants to perform another task.
Enter Y to go back to the main menu.
Enter N to close the program.
This allows users to use different features without running the program again.

**Technologies Used**
Programming Language: C
Compiler: GCC or any compatible C compiler.

**Libraries Used:**
stdio.h – Used to display information and receive user input.
string.h – Used for string-related operations, such as strlen().
ctype.h – Used to convert characters using tolower().

**Programming Concepts Applied**

Variables and Data Types
Input and Output (scanf() and printf())
Conditional Statements (if, else if, and else)
Loops (for and do-while)
Nested Loops
Arrays and Strings
String Functions (strlen())
Character Functions (tolower())
Mathematical Operations
Logical and Relational Operators
